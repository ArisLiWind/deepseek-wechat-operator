# Roadmap

## Phase 1

- Public `dsh-plugin` repo
- Mock-mode demo data
- Digest, find, reply ranking, reply drafting, automation-rule planning
- Command-center landing page

## Phase 2

- Real connector bridge for accessible bot-channel events
- External URL fetch and content parsing
- Memory persistence for long-term user interests and relationship priorities
- Approval queue for yellow and red actions

## Phase 3

- Better semantic retrieval across messages and attachments
- Calendar, task, and spreadsheet action tools
- User-defined daily and weekly digest automations
- Multi-surface expansion into email and browser workflows
